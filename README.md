# MeshWeaver-Zero-Dependency-P2P-Async-Task-Broker
MeshWeaver: Zero-Dependency P2P Async Task Broker

A Python-based project to explore peer-to-peer communication, asynchronous task execution, and distributed task scheduling.

Project goals
- Enable communication between peers.
- Distribute tasks across available workers.
- Execute tasks asynchronously.
- Handle worker failures and collect results.
